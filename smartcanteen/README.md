**MEALS Client** is the cross-platform frontend application for the **MEALS Smart Canteen Ecosystem**. Built with **React 19**, **Vite 8**, and **Tailwind CSS 4**, it delivers a unified experience across:
- **Windows Desktop Executables** (`.exe` via Electron with 1-click installer and portable builds).
- **Android Tablets & Phones** (via Capacitor).
- **Modern Web Browsers** (high-performance SPA).

## ✨ Key Views & Features

### 1. 🛒 Point of Sale (POS) (`src/views/POS.jsx`)
- **Fast Cashier Workflow**: Instant item search, barcode scanning, category filters, and quick-add favorites.
- **Multi-Unit Pricing**: Supports discrete pieces (`pcs`) and continuous bulk measures (`kg`, `g`, `l`, `ml`).
- **Cash & Change Calculation**: Automated change computation with preset bill buttons and customer discount inputs.
- **Offline Mode**: Operates seamlessly when network connectivity is lost, saving sales to local storage and auto-syncing upon reconnect.

### 2. 📦 Inventory Management (`src/views/Inventory.jsx`)
- **Live Stock Tracking**: Real-time stock counts with color-coded warning badges for items below `min_stock`.
- **Product Catalog Management**: Add, update, archive products, define base units, barcodes, categories, and cost/retail prices.
- **Stock Restock & Adjustments**: Direct stock level increments and deduction adjustments.

### 3. 🧠 AI Demand Predictions (`src/views/Predictions.jsx`)
- **Next-Day Demand Forecast**: Visualizes AI/ML sales volume predictions per item generated by the backend XGBoost model.
- **Restock Action Alerts**: Highlights items where projected demand exceeds current inventory.
- **Weather & Context Telemetry**: Displays integrated weather forecasts and school event modifiers.

### 4. 📊 DepEd Financial Reports (`src/views/FinancialReports.jsx`)
- **DepEd Canteen Fund Framework**: Monthly statements tracking Gross Sales, Cost of Goods Sold, Operating Expenses, and Net Income.
- **Statutory Fund Allocations**: Real-time distribution across mandatory DepEd percentage allocations (Feeding 35%, Operations 25%, Clinic 5%, Admin 5%, etc.).
- **Live Excel Export**: One-click download of official DepEd `.xlsx` workbooks with preserved formulas, cell formatting, and school logos.
- **Expense Voucher Proofs**: Upload and preview receipt photos for itemized operational expenses.

### 5. 📈 Analytics & Sales Reports (`src/views/Analytics.jsx`)
- **Interactive Visualizations**: Powered by Chart.js — daily sales trends, top-selling items, revenue by category, and hourly traffic heatmaps.
- **Date Range Filters**: Custom date ranges, monthly views, and school term comparisons.

### 6. 🔐 Security, TOTP MFA & Account Management (`src/views/Login.jsx`, `ManageAccounts.jsx`)
- **Role-Based Views**: Automatic navigation guards based on user role (`admin`, `cashier`, `staff`).
- **Time-based MFA (TOTP)**: Google Authenticator setup with QR code generation, backup recovery codes, and 30-day device trust.
- **Account & Reset Queue**: Administrative password reset approval and MFA reset requests.

## ⚙️ Environment Configuration

Create a `.env.local` file in `smartcanteen/` by copying `.env.example`:

```bash
cp .env.example .env.local
```

### Environment Variables Reference

| Variable | Default Value | Description |
| :--- | :--- | :--- |
| `VITE_API_BASE_URL` | `http://127.0.0.1:8000/api` | Base URL for REST API requests |
| `VITE_API_PROXY_TARGET` | `http://127.0.0.1:8000` | Vite local development proxy target |
| `VITE_NATIVE_API_BASE_URL`| `https://smartcanteen.yourdomain.com` | Absolute API target for mobile & desktop native builds |
| `VITE_OPENWEATHERMAP_API_KEY` | *(Optional)* | OpenWeatherMap API key for live weather forecasts |

## 🖥 Building for Desktop (Electron Windows `.exe`)

To compile the standalone Windows binaries:

```bash
npm run electron:build
```

This generates:
- **`dist-electron/MEALS Setup.exe`**: Full NSIS installer with desktop shortcut, start menu entry, and uninstaller.
- **`dist-electron/MEALS.exe`**: Standalone portable single executable requiring no installation.

### Configuring the Server URL for Desktop Clients

The desktop executable dynamically checks for an external `config.json` file in its folder:
```json
{
  "apiBaseUrl": "https://smartcanteen.yourdomain.com/api"
}
```
This allows distributing the same pre-compiled `.exe` to Admin and Staff PCs while easily configuring the server domain on-site without rebuilding the code.

1. **Build the production web bundle**:
   ```bash
   npm run build
   ```

   ```bash
   npx cap sync android
   ```

3. **Open the project in Android Studio**:
   ```bash
   npx cap open android
   ```

4. Build and deploy the APK directly to your connected Android tablet or phone.

## 🔄 Offline POS Queue & Sync Architecture

When operating in environments with intermittent internet connectivity:
1. **Offline Detection**: `OfflineContext.jsx` monitors browser/client network status.
2. **Local Queueing**: Completed transactions are assigned client UUIDs and stored in IndexedDB / localStorage.
3. **Automatic Resynchronization**: Upon reconnecting, transactions are posted in batches to `/api/transactions/sync`.
4. **Idempotency**: The backend verifies each client transaction ID to guarantee zero duplicate sales records or inventory double-deductions.

## 🔧 Troubleshooting

### 1. API Connection Errors / Network Error on Login
- Ensure your backend server is running (`python app.py` or uvicorn).
- In browser dev mode, check that `VITE_API_BASE_URL` or Vite proxy target in `.env.local` points to `http://127.0.0.1:8000`.
- In the Electron `.exe`, confirm that `config.json` contains the correct `apiBaseUrl`.

### 2. Styles Not Applying Properly
- Tailwind CSS 4 uses modern `@theme` syntax in `src/index.css`. Run `npm run build` to verify clean CSS compilation.

### 3. Financial Report Excel Export Fails
- Ensure the backend has the official template in `backend/report_templates/CANTEEN-REPORT-2025-2026-2 (1).xlsx`.
